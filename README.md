# Oravanti

React + TypeScript + Chakra UI frontend scaffold for the redesigned Oravanti experience.

## Stack

- Vite
- React
- TypeScript
- Chakra UI
- React Router
- TanStack Query
- Axios
- Sonner

## Structure

```txt
src/
  components/
  hooks/
  pages/
  services/
  utilities/
```

## Commands

```sh
npm install
npm run dev
npm run build
npm run lint
```
